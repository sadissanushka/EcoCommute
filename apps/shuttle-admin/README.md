# Shuttle Admin Web Dashboard (Module 2)
**Owner: Chamara WPR (234250D)**

A high-performance operations dashboard for corporate shuttle fleet administrators.

### Features
- **Operations Overview**: Real-time KPI metrics for active vehicles, scheduled runs, and occupancy rates.
- **Shuttle Trips**: Filter and inspect upcoming shuttle runs with departure/arrival windows and booking cutoff triggers.
- **Fleet & Vehicles**: Vehicle layout grids, license plate registries, and passenger capacity limits.
- **Occupancy & Allocations**: Visual representation of vehicle seat arrangements and adjacent-block allocations.

### Running Locally
To launch using Vite:
```bash
npm install
npm run dev
```
Or view directly in any modern browser via `index.html`.
